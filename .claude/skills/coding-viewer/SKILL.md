# 코딩 한눈에 보기 (coding-viewer)

QualCoder 프로젝트(`*.qda` 폴더, 안에 `data.qda`)를 **읽기 전용**으로 읽어 코딩 구간을 한 화면에 모은다.

## 준비

- 이 스킬은 coding-viewer 저장소의 `build_viewer.py`와 `index.html`을 쓴다. 저장소 경로를 모르면 사용자에게 묻거나 `git clone`한 위치를 찾는다.
- Python 3.9 이상. 추가 패키지 없음.

## 절차

1. 프로젝트 경로를 확인한다. QualCoder가 열려 있으면 닫아 달라고 권한다(읽기 전용이라 고장은 없지만 최신 저장분을 읽기 위해서).
2. 만들 위치를 정한다. **저장소 안이 아니라** 사용자의 작업 폴더나 임시 폴더에 만든다.
3. 실행한다.
   ```bash
   python3 <repo>/build_viewer.py "<project.qda>" -o "<작업 폴더>/coding-viewer_<날짜>.html"
   ```
   - 예전 판단을 이어 쓰려면 `--grades "<판단 JSON>"`을 붙인다.
   - 데이터만 필요하면 `--json -o <파일>.json`.
4. 출력된 문서·코드·구간·코딩 수를 사용자에게 알린다.
5. 만든 파일에 원문이 들어 있으므로 밖으로 보내거나 공개하지 말라고 알린다. 아티팩트나 공유 링크로 올리지 않는다.

## 화면에서 할 수 있는 것

- 코드 누르기(여러 개면 모두 붙은 구간), 문서 거르기, 검색, 앞뒤 문맥 보기
- 구간마다 판단 단계(설정에서 바꿈)와 메모, 판단 저장/불러오기(JSON)
- 오른쪽 위 **Reset**: 이 브라우저에 남은 판단·설정·상태를 모두 지운다

## 지킬 것

- QualCoder DB에 쓰지 않는다.
- 코드 빈도를 연구 결과처럼 말하지 않는다. 화면의 수는 참고용이다.
